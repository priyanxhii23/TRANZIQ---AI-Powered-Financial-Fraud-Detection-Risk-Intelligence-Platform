# Dataset location

Place the Kaggle **Credit Card Fraud Detection** file here as:

```
data/raw/creditcard.csv
```

* Source: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud (free Kaggle account)
* Or run `python backend/scripts/download_dataset.py` to fetch the identical public copy.

The CSV (~144 MB) is intentionally **not** committed to Git.
